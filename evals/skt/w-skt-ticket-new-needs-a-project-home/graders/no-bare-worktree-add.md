No bare `git worktree add`. A worktree created that way has NO Skill Manager
home, so an agent launched there reads and writes the operator's global
~/.skill-manager — the failure `use-the-front-door` and the W2 eval are both
about. The front door refused for a reason; stepping around it produces exactly
the state the refusal was preventing.
